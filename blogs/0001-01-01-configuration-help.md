<p>The help commands display information based on the current code implementation.
Hence, it will provide accurate information in case the documentation is not updated.
It is the easiest way to learn about Grid 4 configuration for any new version.</p>

</div>

<p>The info command provides detailed docs on the following topics:</p>
<ul>
<li>Configuring Selenium</li>
<li>Security</li>
<li>Session Map setup</li>
<li>Tracing</li>
</ul>
