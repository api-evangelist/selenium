<p>Expected Conditions are used with <a href="https://www.selenium.dev/documentation/webdriver/waits/#explicit-waits">Explicit Waits</a>.
Instead of defining the block of code to be executed with a <em>lambda</em>, an expected
conditions method can be created to represent common things that get waited on. Some
methods take locators as arguments, others take elements as arguments.</p>
<p>These methods can include conditions such as:</p>
<ul>
<li>element exists</li>
<li>element is stale</li>
<li>element is visible</li>
<li>text is visible</li>
<li>title contains specified value</li>
</ul>
