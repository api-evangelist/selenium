Introduction Selenium RC was the main Selenium project for a long time, before the WebDriver/Selenium merge brought up Selenium 2, a more powerful tool. It is worth to highlight that Selenium 1 is not supported anymore. How Selenium RC Works First, we will describe how the components of Selenium RC operate and the role each plays in running your test scripts.
