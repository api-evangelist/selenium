The implementation of these features is being tracked here: #13993 Remember that to use WebDriver BiDi, you must enable it in Options. For more details, see Enabling BiDi Authentication Handlers Authentication handlers enable you to intercept authentication requests that occur during a network interaction. These handlers are useful for automating scenarios involving authentication prompts, such as Basic Auth or Digest Auth.
